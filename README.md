# homebrew-tap
Homebrew formulae for pravin's tools.

```sh
brew install pravin/tap/letterlock   # terminal word-guessing game
brew install pravin/tap/letterlift    # terminal word-ladder puzzle
brew install pravin/tap/uketuner     # ukulele tuner
brew install pravin/tap/roomy-cli    # disk space analyser (command line)
brew install --cask pravin/tap/roomy # disk space analyser (desktop app)
```
